# mandalink.rayanupadhyay.com

The story of [Mandalink](https://mandalink.org): what it teaches (Mandarin through its 214 Kangxi radicals), what it does now, why it was built twice (a Python and Streamlit first version, then a React and Spring Boot rewrite), how version 2 fits together, and a timeline from the commit history of both repositories.

One static `index.html` plus `logo.png`. No build step: deploy the folder as is (for example as a Vercel project) and point the `mandalink` subdomain at it.

- The app: [mandalink.org](https://mandalink.org)
- Version 2: [RayanUpadhyay/Mandalink2](https://github.com/RayanUpadhyay/Mandalink2)
- Version 1: [RayanUpadhyay/MyChineseApp](https://github.com/RayanUpadhyay/MyChineseApp)

By [Rayan Upadhyay](https://rayanupadhyay.com).
